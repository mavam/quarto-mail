title: Deliver messages through gog's Gmail commands
type: change
authors:
  - mavam
created: 2026-09-22T09:26:38.807651Z
---

Delivery scripts now call gog's first-class Gmail commands instead of raw Gmail API requests:

```sh
gog --account work@example.com gmail send --raw-file - --json --force --no-input <<'QUARTO_MAIL_MESSAGE_…'
```

The approved message appears as readable RFC822 inside the script instead of a base64 JSON blob, and reaches gog on stdin, so delivery no longer writes a temporary copy of the message to disk. Sends, draft creation, draft updates, and threaded replies behave as before.

Running a delivery script now requires gog 0.41 or later. Re-render any script generated by an earlier version.
