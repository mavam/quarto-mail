Quarto Mail turns Markdown email into deterministic plain-text and compact HTML artifacts, making messages easy to review before sending. The initial release adds reusable sender, identity, and signature profiles, named recipients, replies, attachments, and inline rich signatures.

## 🚀 Features

### Add MVP

Quarto Mail turns each Markdown message into deterministic plain-text and compact HTML artifacts plus a reviewable `gog` send command. The initial release supports reusable sender, identity, and signature profiles; named recipients; replies; attachments; and inline rich signatures.
